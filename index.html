Aplicación de Negocio

Analítica SaaS

Nova Analytics

Plataforma de analítica whitelabel para dar seguimiento operativo a la empresa: landing pública, autenticación por correo y contraseña, y un dashboard que consume datos reales. Las fuentes de datos se conectan desde la propia interfaz, que emite una llave de API; los eventos enviados a esa llave viajan por una Edge Function, se consolidan y aparecen en las gráficas en segundos, sin recargar la página.

04 / proyectos

Proyectos y Emprendimiento

Agentes de IA

Agente con herramientas

Py Agent

Agente de IA en Python con interfaz web: razona en ciclo, llama herramientas, lee y escribe archivos y ejecuta comandos de shell. Funciona con cualquier servidor compatible con la API de OpenAI, local o en la nube, y corre aislado en un contenedor Docker sin privilegios.

  • Python
  • FastAPI
  • SQLite
  • OpenAI API
  • Docker
Código
En desarrollo

Second Brain

Un segundo cerebro local: notas en Markdown como fuente de verdad, indexadas en SQLite con búsqueda de texto completo y sin base de datos vectorial. Un LLM local busca, cita y, solo con permiso explícito, edita las notas a través de herramientas; cada cambio queda versionado en git.

  • Python
  • FastAPI
  • SQLite FTS5
  • Svelte
  • TypeScript
  • llama.cpp
